# Codex Runtime 侧栏（v0.2.1）

## 后续修复（未发布）

回合开始页移除解释性提示句。时间线将“摘要”明确为“思考”，详情标题为“思考摘要”，仍只展示日志公开提供的摘要；“背景”改为区分“上下文”和“记录”：已知环境状态、工具清单、推理配置及明确 context 角色的消息属于上下文，其他未分类事件保留为记录，不根据正文关键词猜测类型。上下文标签使用完整三个字，类型列由 28px 调整为 40px，轮次列仍为 34px，Inspector 裁切位置同步对齐。

会话选择器以**当前可见的父子关系**绘制分组。历史父会话已归档、日志缺失或不在最近会话列表中时，该分支作为独立组显示真实会话名，不再使用匿名分支缩进接在上一组后面；其子分支继续按真实 ID 归属。多层分支逐层缩进，深层缩进设上限以保留侧栏内的文字宽度。关闭选择框后的标题采用同样规则。历史 `forked_from_id` 仍保留在悬停说明中，不改写 Codex 数据，也不按同名会话合并。

Inspector 的关联工具 / 命令、其他参数及技术信息继续默认折叠，点击标题后直接展示全部已保留内容，不再嵌套第二个“展开全部”。标题也负责收起，增量刷新保留展开状态和键盘焦点；正文 / 输出预览和原始内容页的现有行为不变。

托盘态下左键点击系统托盘图标切换侧栏：关闭时展开，打开时收起。切换依据窗口的展开目标状态，在 UI 线程上串行处理，支持预热期间取消和动画中途反向；不依赖焦点或动画期间仍为真的窗口可见标志。仅响应一次左键抬起，右键菜单和胶囊模式行为不变。

Inspector 增加命令执行、脚本批量返回和回合结束的阅读模板，保留“概述 / 原始内容”两页。已知 PowerShell / cmd / sh 启动数组在参数无歧义时提取实际命令，完整启动参数与退出码留在技术信息；未知参数组合仍显示原数组，不拼接或重写可执行命令。前置提示区明确区分正常退出、工具报告成功、执行结束但未记录成功标志；输出中的明确测试报告单独突出，仍归属于输出，不把它视作整个项目的成功结论。耗时改用秒 / 分 / 小时显示。

对于完整的 `Script completed / Wall time / Output` 包装，只有输出部分全部由已知命令返回对象组成时才拆成“返回 1 / 返回 2”等独立结果。各项正文正常换行，分别保留状态、退出码、耗时、错误与默认折叠的附加字段；外层脚本耗时单独标明，不传播给子项，也不根据外层结束推断内部全部成功。不猜测各返回属于哪一个内部工具。解析上限为 32 条返回、128 KiB 文本；混杂说明、未知对象、截断或无效 JSON 整体回退原文，不部分吞掉内容。

回合开始 / 结束 / 中断采用明确标题。结束事件直接展示本轮耗时、日志提供的本轮首 token 时间，以及安全 Markdown 排版的最终回复；未知字段默认折叠，ID 与时间戳原值留在技术信息 / 原始记录。首 token 时间只属于本轮，未推算单次模型请求的计时。缺少最终回复时明确提示，不填充其他事件或凭空总结。

## 使用

切换到托盘态后，点击标准系统托盘图标。原有详情窗口现在沿显示器右侧展开，内容宽度为 525 个逻辑像素，高度覆盖可用工作区，不遮挡任务栏。顶部保持状态与 5h / Weekly 额度；缺失的额度窗口不显示。

- 轨迹使用 DSH 风格的统一时间线，事件行高 24px，不再嵌套 Turn / Step 卡片。左侧窄栏标注轮次，右侧彩条、紧凑类型标签和摘要始终对齐；标签通常两个字，“上下文”保留三个字。按 JSONL 文件顺序显示，不按工具归属重排。
- 默认选择当前有效日志最近修改的本地会话；可固定一个会话。列表最多显示最近 40 个**逻辑会话**，同一 `thread_id` 的多份 rollout 合并，不按标题去重。真正的同名分支保留独立身份。固定的会话即使落出最近 40 个也继续保留。
- 正确区分 `rollout-时间-thread_id.jsonl` 与 `rollout-时间-thread_id_rollout_id.jsonl`：前一个 UUID 用于会话身份和标题映射，后一个 UUID 标识具体日志版本。优先读取 `session_meta.id` 确认身份。
- 每 3 秒只读查询本地 `state_N.sqlite` 的 `threads.rollout_path` 与 `name`；使用 SQLite 只读连接读取当前 WAL，不启动或接管 Codex。标题索引 `session_index.jsonl` 为兼容回退（最多末尾 8 MiB，最新完整记录生效）。没有名称记录的条目显示“未命名会话”，不将长文件名当作标题。
- 当前日志由 Codex 索引指定，不按旧文件的修改时间猜测。如果索引不可读，则按文件创建时间戳/日志 ID 回退，并在多版本会话上说明；索引明确指向缺失或未支持的文件时显示不可用提示，**不静默替换成旧轨迹**。
- 选择框在侧栏内部展开，宽度固定为触发按钮宽度，高度最多 360px，并随剩余屏幕空间缩小；内容独立滚动，长标题省略，不使用会按最长选项向窗口外扩展的系统原生 `<select>`。毛玻璃模式使用与侧栏协调的中性灰 / 浅色面板，纯色回退模式沿用侧栏底色。条目为 26px 单行：主会话显示名称，分支以更深的缩进显示“分支 · 短 ID”，自动模式显示“自动跟随”；完整名称、来源、日志数量放入悬停提示，不再占第二行。支持方向键、Home / End、Enter / 空格、Tab、Esc 及点击外部关闭。
- `Live ↓` 跟随新事件。向上滚动会暂停跟随，点击按钮恢复。
- 点击事件打开侧栏内部 Inspector，只覆盖摘要区域。轮次列宽 34px，类型列宽 40px；原时间线的轮次、彩条和类型标签留在原位，不复制另一套导航、不调暗列表。点击露出的原标签直接切换事件，也可在左列上滚动。右侧展示概述、工具参数、关联结果、可用元数据与原始记录。
- Inspector 打开时暂停滚动跟随并临时固定会话，关闭后恢复打开前的列表滚动位置与原来的会话选择模式；点击 `Live ↓` / `跟随 ↓` 可继续跟随。详情抽屉从右侧滑入并渐显（300ms），关闭时反向收回（220ms），可中途反向操作；系统关闭动画或启用减少动态效果时直接切换。原行按事件 ID 就地更新，锁定会话或增量刷新不替换左列节点。Esc 依次关闭会话选择框、Inspector、侧栏；隐藏不退出 Wisland。

### Inspector 概述

- 按事件类型排版，保留“概述 / 原始内容”两页签。用户、助手、系统消息和公开摘要显示安全 Markdown：段落、标题、列表、引用、代码块和表格；正文 13px，代码 12px，不再把整条消息当作 11px 等宽日志。
- 工具调用显示短工具名，命令类使用“执行命令”标题，独立显示实际命令 / 输入与关联结果；其他参数默认折叠。执行结果优先显示输出，关联命令放在折叠区。同一段内容不再在“内容”“参数”“结果”中重复；镜像源只在原始内容页保留。
- 实际记录的状态、模型、耗时与 token 数以前置提示 / 键值行展示。命令类用“进程正常退出 / 异常退出”解释退出码，原值在技术信息；批量返回按项展示结论、耗时，状态原值与退出码留在各项附加字段。关联结果的状态与退出码归属该结果，不冒充调用记录自身的状态。`completed` 只表示执行结束，不自动等于执行成功；只有明确成功字段或退出码才用成功 / 错误色提示。没有单位的 `duration` 保留原值，不猜测秒或毫秒。
- 仅对完整、有效的 JSON 对象 / 数组，以及上面严格识别的完整脚本返回序列进行解码，从已知参数字段提取 `cmd` / `command`，从已知输出包装中分离正文和退出码。无效 / 截断 JSON、补丁及 Windows 路径保持原文本；未知字段可在附加字段或原始内容中查看，未知事件使用文本 / JSON 回退。
- 概述文本默认最多预览 240px，可展开、收起和复制该段保留内容；“原始内容”页的 JSONL 记录及镜像默认完整展开，直接滚动阅读，也可手动收起。这是界面折叠，不会恢复读取器已截断的数据。底部标明数据限长，日志中的截断提示保留。实时刷新保留用户的展开 / 收起状态、技术信息开关和详情滚动位置。
- `call_id`、源类型、字节偏移等置于默认折叠的“技术信息”，不挤占正文。毛玻璃模式下 Inspector 同样采用中性灰 / 浅色不透明覆盖层，避免底下时间线透出。
- Markdown 使用 [Marked](https://marked.js.org/using_advanced) 解析并经 [DOMPurify](https://github.com/cure53/DOMPurify) 标签 / 属性白名单过滤。原始 HTML 显示为文字，图片只显示说明，链接只显示文字和悬停地址，不执行脚本、不请求远程资源、不跳转离开侧栏；复制只在用户点击时发生。依赖许可证随前端资源保留在 `third-party/`。

侧栏失焦保持显示与背景材质，不切换为 Windows 非活动态的灰白背景，也不抢回输入焦点。通过隐藏按钮、Esc、Alt+F4 或切回胶囊关闭。顶部按钮顺序为刷新额度、设置、隐藏；底部不再显示“显示胶囊”，改用托盘右键菜单返回。托盘态右键菜单不再显示“切换至托盘态”。

## 数据契约

读取 `$CODEX_HOME/sessions/**/*.jsonl`，未设置时使用 `%USERPROFILE%\.codex\sessions`。仅识别规范的 `rollout-*.jsonl`；历史引用可读取 `archived_sessions` 内的未压缩源日志，但归档会话不列入选择框。不访问 `auth.json`，不修改 Codex 配置或数据库，不建立新的 Codex 控制连接，也不上传轨迹。

每 500ms 从已选文件的上次字节偏移继续读取；每 3 秒重新发现最近会话。等待完整换行后才解析，支持跨写入批次的 UTF-8 字符。日志缩短、更换或已读边界被重写时重建视图。同步速度受 Codex 写盘频率影响，不等同于逐 token 的运行时事件流。

分页日志沿 `session_meta.history_base` 解析保留的历史链。该字段中的 `thread_id` 实际引用具体 rollout ID，读取严格止于 `end_byte_offset`，带 ordinal 的记录还受 `end_ordinal_exclusive` 限制，不混入回退后丢弃的内容。历史链最多 64 段；源缺失、压缩、循环或边界异常时说明仅加载部分历史。事件 ID 使用 `rollout_id:byte_offset`，避免不同日志相同偏移产生详情串线。同一会话的当前日志切换时自动重建轨迹，手动固定的是会话而非旧文件。

- 支持 `event_msg` 的回合开始、完成、中断及消息；`response_item` 的消息、公开摘要、工具调用与结果；`compacted`；以及新格式 `item_completed` 的常见 TurnItem。
- 轮次使用日志中的 `turn_id`，左侧编号仅是本次加载记录中的顺序，历史裁剪时不重编号。没有标识的记录显示“未关联”，不猜测所属回合。
- 模型调用圆点只来自带非空 `response_id` 的 `token_usage_record` 或 `event_msg.raw_response_completed`；同一轮次的相同 ID 合并为一个标记。这些是**完成记录**，不推算请求起点、耗时、流式中间状态或缺失调用。`token_count` 是可能累计/重放的用量更新，不作为模型调用边界。旧日志没有这些字段时显示说明，不将 Step、工具调用或助手消息冒充模型调用。
- 工具和结果继续通过真实 `call_id` 在 Inspector 内关联。延迟结果保留原轮次标识，但在时间线中停留于实际写入位置。
- 同一消息的旧事件和原始响应镜像合并为一行，Inspector 保留两条来源。未知事件仍可查看原始记录。
- 未记录的耗时、成功状态和模型信息不推算。收到工具结果不自动等同于成功；日志尚无完成记录时不声称任务仍在运行。
- 只呈现公开摘要；省略原始推理正文、加密内容和二进制字段。Inspector 消息可显示安全 Markdown，代码与原始 HTML 始终作为文字显示。
- 顶部状态灯和额度继续使用现有全局监控链路，不代表下拉框所选历史会话的当前状态。

内存与读取有界：首次的历史内容预算为整条有效历史链合计 4 MiB，从最新日志向前分配，优先保留最近内容；后续活动日志每轮增量最多 512 KiB。发现阶段只读取每份日志的首行元数据，上限 2 MiB；正文单行超过 2 MiB 跳过；列表保留最近 800 个事件；Inspector 对原始记录和内容做限长处理，每段文本最多 32K 字符。超长文本显示截断提示，原始内容页同时标注限长与字段省略。压缩日志、云端会话，以及未落盘的内部事件不在本次数据源范围内。

## 窗口与动画

沿用 v0.1.5 的单窗口生命周期、Desktop Acrylic、高对比度/省电回退、隐藏首帧合成预热和可取消动画编号。展开 240ms 向左减速，收回 170ms 向右；内部内容宽度固定，通过原生视口宽度裁切，不逐帧修改窗口区域、透明度或毛玻璃属性。

Windows 无标题栏窗口仍有非客户区边距。Tauri `set_size` 接收客户区尺寸，而 `GetWindowRect` 返回外框尺寸，布局显式处理这个差异，保证外框右边缘不越过工作区、下沿不进入任务栏。显示器分辨率/DPI/工作区改变时更新已打开侧栏；隐藏侧栏不会因布局变化被打开。

侧栏创建后、首次显示前，在所属 UI 线程安装原生子类过程。仅将 `WM_NCACTIVATE` 的材质绘制状态交给 `DefWindowProcW(TRUE, -1)`，保持 Acrylic 活动外观并避免非客户区重绘；真实激活、失焦和键盘消息照常传递，销毁时移除子类。不在失焦后重新设置背景，不调用聚焦来维持外观。依据 [Microsoft 的非客户区激活消息说明](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-ncactivate)。
