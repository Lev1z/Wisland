# Runtime 性能验证

此轮优化范围是隐藏时暂停无用工作、减少详情深拷贝、统一 Codex 状态获取。不更改原生窗口动画、材质、预热或隐藏复用；不减少日志解析范围，不改变模型关联规则。

## 可复现负载

`node scripts/measure-runtime-perf.cjs <绝对 EXE 路径> [每场景秒数，默认 30]` 启动自己的实例。先退出用户实例，再串行测试旧版和新版，测量期间不运行编译和其他回归。脚本使用独立 `CODEX_HOME`、APPDATA、LOCALAPPDATA 和 WebView profile；不读取真实会话，不修改用户配置。调试接口只绑定 loopback，测完关闭自己创建的进程。产物与报告留在忽略的 `target/runtime-perf-*`。

固定 36 份会话文件，目标会话预置 50 回合、1,000 条事件记录（受产品 800 条保留上限约束），工具参数 1 KiB、结果 2 KiB。预热 10 秒后每 500ms 追加 2 KiB 助手文本。依次测隐藏、侧栏、Inspector，各场景读取进程树起止计数；CPU 按逻辑处理器数归一化。最终内存为每场景结束值，不是峰值。Inspector 阅读固定工具记录，追加发生在同一文件，测试无需在线模型。

这是合成持续写入负载，包含 WebView 调试连接，不能把内存绝对值当成正常桌面空闲占用。比较对象应为同协议测试的前后版本；真实环境下约 31 秒的 v13 测量（私有工作集约 129 MiB、CPU 约 0.62%）作为独立观察，不能直接与合成负载对比。进程 I/O 计数包含缓存和管道，不等于物理磁盘流量。跨场景保留进程和既有页面，因此后一个场景内存还受到前面场景的影响；短测不能判定泄漏。

## 功能回归

详情存储改为共享不可变原始 JSON 和独立的模型关联覆盖层，快照及标题克隆不再深拷贝正文；镜像更新采用写时复制，详情 IPC 才合并序列化，两种来源和原始内容保持兼容。Codex 状态由单个后端采样器每 2 秒读取，命令只读缓存；相位变化直接更新托盘并推送给胶囊，隐藏胶囊不绘制，显示时读取缓存。清除状态会同步更新缓存和两种显示模式，不再叠加第二个轮询周期。

- `node scripts/test-hidden-work.cjs`：隐藏胶囊不查询状态或刷新时钟，显示后恢复。
- `cargo test --lib`：解析、模型关联、历史链、窗口和动画单元回归。
- `node scripts/test-tray-native.cjs --release --display --runtime`：真实 WebView2、隐藏暂停及重新展开追平、原始内容、Inspector、快速反向动画与几何边界。
- `node scripts/test-tray-ui.cjs`：深浅主题、DPI、选择器、Inspector、安全正文和滚动状态。
