# v0.1.5 托盘动画修复复盘

## 最终方案

保留一个托盘详情窗口：隐藏初始化，反复显示与隐藏，退出应用时销毁。动画采用原生窗口视口高度变化，内部内容维持完整高度；窗口下沿受任务栏上边缘约束。展开约 240ms，末尾减速；收起约 170ms。

任务栏边界优先从所在显示器的 Shell 任务栏窗口获取，以工作区边界作为回退。每帧更新后读取实际窗口矩形，若下沿越界则中止显示。首次可见尺寸在 DWM cloak 状态下准备，并等待合成后再露出；不在显示之后重新启用毛玻璃。

## 排查中学到的事

1. **先区分三层问题。** WebView 内容、原生窗口非客户区、DWM 毛玻璃是不同的绘制层。截图里的白边不能仅凭颜色归因于页面首帧。早期仅增加预热和修改动画时长，没有处理原生边缘及裁切方式。
2. **复用窗口是基础，不是闪烁修复本身。** 本次窗口一直复用，问题仍出现在重新显示和动画期间的合成状态变化。
3. **固定裁切线应成为几何约束。** 移动整个窗口到屏幕之外，或只移动 24px 后隐藏，分别造成穿过任务栏和中途消失。最终让原生视口承担裁切，不再逐帧修改 SetWindowRgn。
4. **预热必须对应实际首帧。** 预热完整窗口后立即改变首帧尺寸，会再次使之前准备的表面失效。应先准备实际起始视口，再等待合成和显示。
5. **别叠加帧等待。** 每帧调度、绘制结束后再固定等待 16ms，会增加帧间隔。改为按合成节奏推进，并在执行帧时用真实经过时间计算进度。DwmFlush 不在 UI 线程执行。
6. **原生窗口不能随意缩到零。** 实测极小外部高度导致 Tauri 得到负的客户区高度并在分配绘制表面时崩溃。终端极小片段使用 cloak 隐藏，避免无效尺寸；这个边界必须做原生测试。
7. **旧回调必须能取消。** 快速关闭、重开、切回胶囊都会让之前的动画或预热过期。使用递增的转换编号，在执行每帧和结束回调前核对，防止旧回调隐藏新窗口。
8. **自动化通过不等于视觉通过。** Rust 单测可验证几何和状态；浏览器测试可验证排版；原生测试可验证真实窗口开关。白边、毛玻璃闪烁和任务栏遮挡仍需过程截图或录屏与用户实机验收，不能用静止截图替代。

最终版本在用户连续实机反馈后确认解决。过程中的单独改动并未逐项做隔离实验，因此不把某一个 API 当作所有闪烁的唯一原因。

## 回归检查

- 两条额度、仅周额度、额度不可用；异步额度返回导致行数变化。
- 首次展开、连续展开、动画中反向操作、Esc、失焦、切回胶囊。
- 任务栏上沿固定、窗口实际下沿不越界，内部文字与页脚不随视口缩小重新排版。
- 深浅主题、不同 DPI、负坐标副屏，以及系统关闭透明效果或动画的回退行为。
- 录制展开与收回全过程，检查首帧、途中和最后几帧，而不只查看展开后的状态。

测试入口：`cargo test --lib`、`npm run build`、`scripts/test-tray-ui.cjs`、`scripts/test-tray-native.cjs`。两个界面脚本使用项目内 `target/tray-qa-tools` 的 Playwright，安装方式见脚本注释。原生测试运行本地 debug 构建，不修改保存的启动模式。
