# Wisland v0.2.2 — Runtime 阅读体验与后台优化

本版改进时间线关联与 Inspector 可读性，并减少隐藏侧栏时的后台工作。保留现有胶囊、额度环、媒体、Obsidian、窗口材质与滑入 / 收回动画。

## 时间线与会话

- 模型标题前置到关联内容之前，保留平铺列表、彩条和类型标签；实时输出先显示待关联，响应身份到达后原位补全，保留选中项与滚动位置。
- 优先使用明确响应 ID；缺少直接关联时，仅在同回合、同来源的连续区间内保守推断。工具结果通过真实 `call_id` 关联，延迟结果不搬动位置，嵌套工具不误算为新模型请求。
- 用量记录显示“已记录用量”，只有明确完成事件才显示“响应已结束”；不根据标题位置生成请求开始时间、耗时或成功结论。
- 修复父会话缺失或归档时的分支错组，独立展示可见根会话并保留多层分支身份。
- “上下文”“思考”等标签更明确；移除回合开始的多余提示句。

## Inspector

- 上下文规则正文使用安全 Markdown 排版，已识别环境字段直接展示；区分完整快照和增量更新，未知字段默认折叠。
- 压缩摘要、保留上下文、用量检查点及技术字段分开呈现。没有明确摘要时说明缺失，不将整份历史或累计用量冒充摘要、压缩比例。
- 命令优先显示实际执行内容；严格识别的批量返回逐项呈现输出、状态与耗时。回合结束直接显示最终回复和本轮计时。
- 关联工具和技术信息默认折叠，一次点击完整展开，不再嵌套“展开全部”。原始 JSONL 与镜像仍默认展开，读取上限和字段过滤保持不变。
- 点击托盘图标可展开或收起侧栏，支持快速连续点击与动画中途反向。

## 后台与存储优化

- 隐藏侧栏时暂停自动日志读取、目录扫描和时间线发布；展开时校验当前日志并按既有预算追平。额度与状态灯继续后台更新。
- 隐藏胶囊不再刷新时钟或重复查询状态；统一由后端采样，变化时推送，显示时读取最新缓存。
- 原始详情共享存储，模型关联信息单独维护，减少快照与模型视图的深拷贝；镜像更新采用写时复制。
- 保留初始化窗口、首帧预热、毛玻璃及原生动画，不通过反复销毁窗口节省资源。

在固定持续写入的合成测试中，隐藏状态整机 CPU 约 1.10% → 0.21%，私有驻留内存约 492 → 249 MiB；展开侧栏与 Inspector 时的内存也降低。前台 CPU 未呈现稳定降幅。以上是带调试连接的特定负载结果，不等同于日常空闲占用或所有机器的固定降幅，完整方法与结果见[性能报告](../performance.md)。

## 安装与升级

下载 **Wisland_0.2.2_x64-setup.exe**。先从托盘退出旧版，再运行安装包；设置侧栏与“关于”均更新为 **0.2.2**。Windows x64、WebView2 和可选集成要求不变。

Runtime 继续只读本地 JSONL，不接管 Codex、不上传轨迹。本版仅完成 Rollout Trace 隔离能力验证，未启用真实会话追踪，也未将其接入产品读取链路。
