# Wisland v0.2.1 — Codex Runtime 侧栏

本版本汇总 v0.1.5 之后的 Runtime 可视化与桌面体验改进。

## Runtime 侧栏

- 标准托盘图标打开约 525 个逻辑像素宽的右侧侧栏，高度覆盖工作区并避开任务栏；顶部固定显示 Codex 状态和 5h / Weekly 额度。
- 保留原生毛玻璃、深浅主题和无标题栏窗口，从屏幕右侧展开与收回。失焦保持显示与材质外观，不抢回焦点。
- 顶部依次放置刷新额度、设置和隐藏按钮；移除底部重复的“显示胶囊”入口，托盘右键菜单不再提供当前已启用的托盘态。
- 修复分辨率、DPI 和工作区变化后的胶囊定位及侧栏边界。

## Trajectory 与会话选择

- 通过只读增量监听本地 JSONL，呈现紧凑、对齐的统一时间线；保留彩条和两字类型标签，标注加载范围内的轮次及实际记录的模型调用完成点。
- 支持滚动与自动跟随最新事件，工具结果按真实 `call_id` 关联，不改变日志顺序。
- 映射 Codex 会话名称，按稳定会话 ID 合并多份 rollout；真正的分支独立显示为“分支 · 短 ID”。
- 优先使用本地索引指定的当前有效日志，并沿历史引用读取保留内容；缺失、压缩或不支持的历史有明确提示。
- 选择框在侧栏内部展开，长标题省略、分支加深缩进，使用与侧栏一致的配色，支持键盘导航。

## Inspector

- 详情从右侧平滑滑入，仅覆盖事件摘要；原有轮次、彩条和类型列留在原位，可点击切换事件。关闭时恢复列表及原来的滚动位置。
- 概述按事件类型排版：消息显示安全 Markdown，工具调用突出命令与参数，结果优先显示输出；状态、耗时、退出码及模型用量只展示实际记录的字段。
- 去掉重复的正文、参数和结果；技术字段默认折叠，长概述支持展开、收起与复制。正文 13px，代码 12px。
- **“原始内容”页的 JSONL 与镜像记录默认完整展开**，无需再点击“展开全部”；手动收起的状态在增量刷新时保留。
- 日志里的 HTML 仅显示为文字，不执行脚本、不加载远程图片。保留原始记录页以及现有的限长、加密 / 二进制字段省略规则。

## 安装与升级

下载 **Wisland_0.2.1_x64-setup.exe**。更新前先从系统托盘退出正在运行的 Wisland，再运行安装包。设置侧栏与“关于”均显示 0.2.1。

Windows x64 安装包包含应用和卸载入口；无需单独下载构建目录中的裸 EXE。WebView2 与 Codex CLI 等可选集成环境沿用原有要求。

## 数据范围

Runtime 功能不接管 Codex Desktop，不修改 Codex 配置或数据库，也不上传轨迹。初始历史读取合计最多 4 MiB，列表保留最近 800 个事件，详情文本有 32K 限长；“原始内容”默认展开不代表取消读取限制。未落盘、已压缩或未公开的信息不会被虚构。

现有开发工具链的 npm audit 告警未在本版混入升级，记录于 Runtime 文档；本次生产依赖审计无已知告警。
