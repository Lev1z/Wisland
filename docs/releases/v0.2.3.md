# Wisland v0.2.3 — 自动更新与统一外观

## 软件更新

- 设置“关于”新增自动更新检查，默认启动时检查，最多每天一次；也可点击“检查更新”。
- 发现新版本后由用户确认下载，校验更新签名后才启动安装程序。不会静默安装，不退出 Codex 或其他应用。
- 更新区域压缩为两行，检查按钮与上次检查时间右对齐；失败自动打开跟随主题的弹窗，右下角提供手动下载和关闭。
- Release 附带安装包、更新签名与 `latest.json`，供后续版本检查使用。签名私钥不随源码或安装包分发。

## 主题与毛玻璃

- 主题提供暗黑、毛玻璃；边框独立提供关闭、彩虹、白色，可自由搭配，并同步到胶囊、设置与 Runtime 侧栏。
- 删除边框动图导入与选择，保留胶囊左右图标的图片 / GIF 素材。旧边框素材数据不主动删除。
- 胶囊使用局部圆角 Windows Composition 背景层，修复毛玻璃染暗整个透明宿主矩形的问题；设置与侧栏沿用原生 Desktop Acrylic。
- 毛玻璃设置菜单只绘制一层侧栏底色，不再叠加两个灰色动画底层，消除入场变深与结束跳色。
- 保留既有胶囊、菜单、侧栏和 Inspector 的位移、时长与入场动画。系统不支持材质或禁用透明效果时使用纯色回退。

## 设置与右键菜单

- 删除重复的说明、小标签和素材空库提示；统一按钮层级、卡片间距及列宽，播放器显示友好名称，原始标识保留在悬停提示中。
- 胶囊右键：收起、设置、切换至托盘。
- 胶囊模式的托盘右键：设置、切换至托盘、退出。
- 托盘模式的托盘右键：设置、切换至胶囊、退出。

## 安装与数据范围

下载 **Wisland_0.2.3_x64-setup.exe**。先从托盘退出旧版，再运行安装包；“关于”和版本元数据均为 **0.2.3**。v0.2.2 及更早版本需手动安装本版，之后可通过新增功能检查后续更新。

Runtime 继续只读本地 JSONL，不上传轨迹，不接管 Codex。优先按 `CODEX_HOME` 定位，否则使用当前用户的 `.codex`，不固定某台机器的路径。

本版包含 Rust、主题 / 更新界面及原生窗口回归。胶囊材质额外使用自建棋盘背景进行桌面合成截图与外侧像素比较，覆盖展开与收起，避免仅凭网页截图或窗口区域参数判断修复。
